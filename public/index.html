FROM DEMO TO REAL-WORLD SERVICE

Know what’s connected.

A working local demo today. A clear path to Cardano Preprod.

Think of Guardian as a helper for a crypto loan.

Your collateral is the crypto you deposit to back a loan. If its value falls too far, the lender can take collateral to repay your debt — that’s liquidation. Guardian watches the safety margin and calculates a response using funds you have set aside.

HONEST BY DESIGN
TWO SEPARATE MONEY FLOWS

Paying the agent ≠ rescuing the loan.

Customer pays for analysis

Customer → Masumi → agent’s seller wallet

User funds a loan rescue

User’s authorized reserve → lending protocol

Hiring Guardian does not give it permission to spend wallet funds. This dashboard implements neither live lending execution nor wallet signing.
